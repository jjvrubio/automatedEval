## Cálculo de la Calificación Final

**Puntuación total:** Cada criterio se evalúa en una escala de 1 a 4.

**Fórmula de cálculo:**
```
Calificación Final = Σ (Nivel obtenido × Peso del criterio) / Σ Pesos
```

**Ejemplo de cálculo:**
- PC1 (Columna Vertebral): Nivel 3 × 20% = 0.60
- PC1 (Referencias): Nivel 4 × 5% = 0.20
- PC2 (Kit Canónico): Nivel 3 × 15% = 0.45
- PC2 (Herramientas adicionales): Nivel 2 × 5% = 0.10
- PC2 (Integración PC3): Nivel 3 × 5% = 0.15
- PC3 (Coherencia ontológica): Nivel 4 × 15% = 0.60
- PC3 (Trazabilidad): Nivel 3 × 10% = 0.30
- PC3 (Profundidad): Nivel 3 × 5% = 0.15
- PC4 (Falsabilidad): Nivel 3 × 10% = 0.30
- PC4 (Ausencia de doxa): Nivel 4 × 5% = 0.20
- PC4 (Coherencia objetivos): Nivel 3 × 5% = 0.15

**Total:** 0.60 + 0.20 + 0.45 + 0.10 + 0.15 + 0.60 + 0.30 + 0.15 + 0.30 + 0.20 + 0.15 = **3.20**

**Interpretación:**
- **1.0 - 1.5:** Doxa predominante (rechazado o revisión mayor)
- **1.6 - 2.5:** Flujo epistémico débil (revisión sustancial requerida)
- **2.6 - 3.5:** Flujo epistémico sólido (aprobado con mejoras menores)
- **3.6 - 4.0:** Flujo epistémico riguroso (aprobado con excelencia)

## Instrucciones de Uso para el Evaluador

### Paso 1: Lectura rápida (5 minutos)
Lee el Resumen y las Conclusiones para tener una visión general del flujo.

### Paso 2: Evaluación por Punto de Control
Evalúa cada criterio de la rúbrica, asignando un nivel (1-4) según la descripción que mejor se ajuste.

### Paso 3: Identificación de rupturas del flujo
Para cada criterio con nivel 1 o 2, identifica específicamente dónde se rompió el flujo epistémico usando los tests de auditoría:
- **Test del "Por lo tanto"** (PC1)
- **Test de la "Secuencia Lógica"** (PC2)
- **Test de la "Trazabilidad de la Causa Raíz"** (PC3)
- **Test de la "Falsabilidad"** (PC4)

### Paso 4: Cálculo de la calificación
Aplica la fórmula de cálculo para obtener la calificación final.

### Paso 5: Feedback para reconstrucción
Usa la **Guía de Feedback para Reconstrucción** (que desarrollaremos a continuación) para proporcionar comentarios específicos y accionables.
