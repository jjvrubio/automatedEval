1. Both source files, thesis and references, are to be chosen via file system native user interface.
2. Thesis document format could alternatively be a docx or PDF document.
3. Refences document is a json format file.
4. Extract the thesis text using Quartz, do no include annexes.
5. Use the extracted text for preparing the markdown report whic will:
   1. How many citations are using references in the list.
   2. How many citations does not appear in the reference list.
   3. identify citations which are properly using APA 7 citation format.
   4. identify citations which are not applying APA 7 citation format.
   5. How many refrences are not cited in the thesis.
   6. List the references not cited in the thesis.
