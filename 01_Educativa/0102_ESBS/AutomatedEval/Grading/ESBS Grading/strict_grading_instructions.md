# Strict Evaluation Guidelines for ESBS Grading

The evaluation must strictly adhere to the rubric provided. Grading must begin from the lowest level of performance upward, and no level may be granted unless **all** the conditions for that level are fully met.

### 🔒 Ultra-Strict Evaluation Rules

1. **Sequential Threshold Logic**  
   Evaluation must follow a bottom-up logic:
   - Start by checking if the submission meets the criteria for score **0**.
   - If not, consider score **1-3**, and so on.
   - A higher score is only granted if **every requirement of the lower level** is clearly satisfied.

2. **No Score Inflation**  
   - If the student does not include specific evidence, reasoning, or data required for a higher level, **they must not be awarded that score**.
   - Partial fulfillment does **not** justify moving up a scoring bracket.

3. **Critical Structural Coherence Check**  
   - The evaluation must assess whether the student's document has a coherent flow between diagnosis, objectives, methodology, proposal, and conclusions.
   - The logic and argumentative structure must follow the flow of:
     - Problem ➝ Analysis ➝ Solution ➝ Impact.

4. **Model AS-IS / TO-BE Requirement**  
   - No work may receive high marks (8+) unless it clearly articulates the current situation (AS-IS) and desired future state (TO-BE) in a logically connected manner.

5. **Explicit Justification Enforcement**  
   - All scores must be justified explicitly.
   - Each criterion's score must be explained using concrete examples from the student's solution.

6. **Table & Data Verification**  
   - If the rubric expects tables, metrics, or data, their presence, structure, and relevance must be strictly verified.

7. **No Bibliography = Score 0 on Evidence**  
   - If no APA 7 bibliography is included, the “Use of Evidence” criterion must be scored as 0.

8. **Sanction on Missing Sections**  
   - If any section of the table of contents is missing or incomplete, the overall coherence and structure must be downgraded.

These rules override any interpretation that allows for indulgence or benefit of the doubt. Academic rigor and fairness must prevail.
