# Source Control

Use this reference before drafting or updating an offer.

## Required Inventory

Create or update a source inventory with:

- Account and opportunity name.
- Source filename or system name.
- Absolute or workspace-relative location.
- Date/version.
- Owner or approver when known.
- Status: confirmed, draft, historical, superseded, or unknown.
- What the source can prove: scope, pricing, assumptions, legal terms, delivery plan, integrations, assets, or context.

## Minimum Inputs

An offer can be prepared as a draft only when the current opportunity has:

- Client/account identity.
- Audience and language.
- Scope or discovery brief.
- Validated pricing output or a clear instruction to prepare a non-priced discovery draft.
- Current assumptions and exclusions.
- Desired output format and audience: internal, client draft, or client-ready.

If one of these is missing, continue with the non-blocking preparation work and list the missing item by exact name.

## Provenance Rules

- Quote or paraphrase only from located sources.
- Tie each economic scenario to the source that authorizes it.
- Treat historical examples as structure references, not pricing references.
- Never promote a draft to client-ready when critical sources are missing or marked unknown.
