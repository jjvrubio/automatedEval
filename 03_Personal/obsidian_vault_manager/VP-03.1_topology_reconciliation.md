## Riesgos

### Git y movimientos físicos

Un movimiento dentro de iCloud puede aparecer para Git como borrado y alta en
otra ruta, especialmente si los directorios están versionados. Antes de
aceptar cambios se debe revisar `git status` y `git diff --stat`, sin modificar
ni renombrar desde esta fase.

### Enlaces relativos

Los enlaces Markdown relativos pueden cambiar de resolución al mover una
carpeta fuera de `Negocios Digitales`. No se inspeccionó contenido, por lo que
no se puede certificar su integridad. Debe realizarse una comprobación separada
y explícitamente autorizada.

### Configuración de plugins

Ambas bóvedas trasladadas conservan `.obsidian` y archivos del plugin Local REST
API por nombre y metadatos. No se leyó `data.json` ni se verificaron puertos,
credenciales, certificados o versiones; no se puede asumir que esas
configuraciones sigan siendo operativamente correctas.

### iCloud

La topología visible localmente puede no coincidir temporalmente con otros
dispositivos si hay archivos deshidratados, conflictos o sincronización
pendiente. La operación posterior debe hacerse con iCloud estable y con una
copia del catálogo.

### Duplicación de plugin

`obsidian-local-rest-api` aparece por nombre en Scaling Up y MIU. Esto no es un
duplicado de bóveda ni una prueba de misma versión: no se compararon
contenidos. Cada bóveda debe conservar identidad, credencial, certificado y
puerto independientes cuando se configure en fases posteriores.
