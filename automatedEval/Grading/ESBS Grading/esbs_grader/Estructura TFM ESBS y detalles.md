# Ancilliary Elements

## References 

All sources must be properly cited following an official citation style. The recommended formats are: 

- APA (American Psychological Association): APA Citation Guide 
- Harvard Referencing: https://librarydevelopment.group.shef.ac.uk/referencing/harvard.html 
- Chicago Style: https://www.chicagomanualofstyle.org/home.html 



Ensure that all in-text citations correspond to a full reference in the bibliography. References should be formatted consistently and include all necessary details (author, year, title, publisher, and link if applicable). 

## Appendices 

Appendices include additional information that supports the project but is not essential for understanding the main text. 

Examples of appendices: 

- Raw data from research, surveys, or interviews. 
- Detailed calculations or financial models. 
- Extended case studies or background information. 
- Supplementary graphs, images, or reports that provide additional context. 



## Figures, Tables & Graphs 

Figures, tables, and graphs that facilitate understanding and enhance readability should be included within the main body of the document. These elements must be numbered and referenced within the text.   Each figure, table, or graph should have: 

- A title explaining its content. 
- A source citation if it is not original work. 
- A reference in the main text to indicate its relevance.
