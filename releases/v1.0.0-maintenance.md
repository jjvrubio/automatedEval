# v1.0.0-maintenance (2025-10-29)

Resumen
-------

Versión de mantenimiento que endurece y documenta el script de limpieza de localizaciones de Microsoft Office.

Cambios principales
------------------

- `scripts de mantenieminto/remove_office_languages.zsh`
  - Limita el glob para evitar recorridos recursivos masivos dentro de bundles.
  - Añade una lista de tokens protegidos (ej: Base.lproj, DFonts, Office Themes, Metadata.appintents, sdx, etc.).
  - Corrige expansiones de arrays para evitar problemas de word-splitting.
  - Añade `--no-sudo` para permitir dry-runs en entornos sin tty.
  - Añade contador de seguridad (límite 5000 entradas) para abortar si se detecta un recorrido excesivo.

- `scripts de mantenieminto/README.md`
  - Documentación de uso, advertencias y ejemplos de ejecución (dry-run, backup).

Comprobaciones recomendadas
--------------------------

1. Ejecutar en modo simulación sin sudo:

```bash
zsh "scripts de mantenieminto/remove_office_languages.zsh" --dry-run --no-sudo --apps "Word Excel"
```

2. Verificar que las rutas importantes (Base.lproj, DFonts, Office Themes, Metadata.appintents, sdx, AppIntents*) no aparecen para eliminación.

3. Si todo OK, ejecutar con respaldo:

```bash
zsh "scripts de mantenieminto/remove_office_languages.zsh" --backup --backup-dir "$HOME/Desktop/OfficeBackups" --apps "Word Excel"
```
